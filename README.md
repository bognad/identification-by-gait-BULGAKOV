Этот проект использовался для написание статей и анализа этого решения (чисто ручной подход)

В данной работе используется только математика без ИИ.
Точки проставляются в ручную на каждый кадр. Всего, по мнению разработчиков, необходимо 2 шага или 60 кадров на человека, чтобы его походку полностью проанализировать.

На один кадр уходит около 12 с.

Точки:
- Нос (либо голова)
  
- Плечи
- Локти
- Запясти
  
- Торс
  
- Колени
- Голень
- Пятка
- Носочек ноги
